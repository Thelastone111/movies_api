# Movies API

Учебный проект CRUD API для управления каталогом фильмов.

## Описание проекта

Асинхронное REST API на FastAPI для управления базой данных фильмов, созданное на воркшопе. Позволяет добавлять, просматривать, изменять и удалять фильмы, а также фильтровать и сортировать список. Код разделён на слои: модели, схемы, репозитории и роутеры.

## Основные возможности

- Создание, получение, полное (`PUT`) и частичное (`PATCH`) обновление и удаление фильмов (CRUD)
- Получение списка фильмов с пагинацией (`limit` / `offset`)
- Фильтрация по году выпуска и минимальному рейтингу
- Сортировка по названию, году, рейтингу и id (по возрастанию и убыванию)
- Валидация входных данных на уровне Pydantic и ограничения на уровне БД
- Версионирование схемы базы данных через миграции Alembic
- Автоматическая интерактивная документация (Swagger UI)

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/Thelastone111/movies_api.git
cd movies_api
```

### 2. Создание виртуального окружения и установка зависимостей

```bash
python -m venv venv

# Linux / macOS
source venv/bin/activate
# Windows (PowerShell)
venv\Scripts\activate

pip install -r requirements.txt
```

### 3. Применение миграций

Команда создаст файл базы данных `movie.db` и таблицу `movies`:

```bash
alembic upgrade head
```

### 4. Запуск приложения через uvicorn

```bash
uvicorn src.main:app --reload
```

Приложение будет доступно по адресу <http://127.0.0.1:8000>.
Интерактивная документация: <http://127.0.0.1:8000/docs>.

## Основные эндпоинты

| Метод | URL | Описание | Успешный ответ |
|---|---|---|---|
| `GET` | `/` | Проверка работы API | `200` |
| `GET` | `/movies/` | Список фильмов (фильтры, сортировка, пагинация) | `200` |
| `GET` | `/movies/{movie_id}` | Получить фильм по id | `200` / `404` |
| `POST` | `/movies/` | Создать фильм | `200` / `422` |
| `PUT` | `/movies/{movie_id}` | Полностью заменить данные фильма | `200` / `404` / `422` |
| `PATCH` | `/movies/{movie_id}` | Частично обновить фильм | `200` / `404` / `422` |
| `DELETE` | `/movies/{movie_id}` | Удалить фильм | `200` / `404` |

Пример создания фильма:

```bash
curl -X POST http://127.0.0.1:8000/movies/ \
  -H "Content-Type: application/json" \
  -d '{"title": "Начало", "genre": "Фантастика", "rating": 8.8, "year": 2010}'
```

Ответ:

```json
{"title": "Начало", "genre": "Фантастика", "rating": 8.8, "year": 2010, "id": 1}
```

## Фильтрация и сортировка

Параметры передаются в query-строке запроса `GET /movies/`:

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `year_min` | int | — | Фильмы не старше указанного года (`year >= year_min`) |
| `year_max` | int | — | Фильмы не новее указанного года (`year <= year_max`) |
| `min_rating` | float | — | Минимальный рейтинг (`rating >= min_rating`) |
| `order_by` | str | `-rating` | Поле сортировки |
| `limit` | int | `50` | Количество записей на странице (допустимо от 1 до 100) |
| `offset` | int | `0` | Сколько записей пропустить |

**Поля сортировки** (`order_by`): `title`, `year`, `rating`, `id`.
Префикс `-` означает сортировку по убыванию, например `-year`.
Если передано неизвестное значение, используется сортировка по умолчанию `-rating`. Для стабильного порядка при равных значениях дополнительно применяется сортировка по `id` по возрастанию.

Пример: фильмы 2000–2020 годов с рейтингом от 8, самые новые первыми, вторая страница по 10 записей:

```
GET /movies/?year_min=2000&year_max=2020&min_rating=8&order_by=-year&limit=10&offset=10
```

## Модель данных

Таблица `movies`:

| Поле | Тип | Описание |
|---|---|---|
| `id` | Integer | Первичный ключ, автоинкремент |
| `title` | String | Название фильма (индексируется) |
| `genre` | String | Жанр |
| `rating` | Float | Рейтинг от 0 до 10 |
| `year` | Integer | Год выпуска |

Схемы Pydantic:

- `MovieCreate` — данные для создания и полной замены фильма (`title`, `genre`, `rating`, `year`)
- `MovieUpdate` — то же самое, но все поля необязательны (для `PATCH`)
- `MovieOut` — ответ API: поля фильма и `id`

Правила валидации на уровне API:

- `title`: строка от 2 до 200 символов
- `genre`: строка от 2 до 100 символов
- `rating`: число от 0 до 10
- `year`: от 1888 до текущего года

При нарушении правил API возвращает `422 Unprocessable Entity`.

### Ограничения базы данных

- `id` — первичный ключ
- `title`, `genre`, `rating`, `year` — `NOT NULL`
- `check_movie_rating_range` — `rating >= 0 AND rating <= 10`
- `check_movie_year_1888` — `year >= 1888` (год первого в истории фильма)
- Индексы по полям `id` и `title`
